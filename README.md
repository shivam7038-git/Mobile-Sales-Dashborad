# 📱 Mobile Sales Dashboard

This repository contains an interactive Power BI dashboard for analyzing mobile phone sales across various dimensions such as city, brand, model, payment method, and time.

## 🔍 Overview

The Mobile Sales Dashboard provides insights into:

- 📊 **Total Sales**: ₹769M across all months
- 📦 **Total Quantity Sold**: 19K units
- 💳 **Transactions**: 4K total transactions
- 💰 **Average Price**: ₹40.11K per unit

The dashboard includes filters for:

- 📍 **City**
- 🏷️ **Brand & Model**
- 💳 **Payment Method**
- 📅 **Year, Quarter, Month, Day**

## 📌 Key Visualizations

- **Sales by City**: Compare total revenue across major Indian cities like Delhi, Mumbai, Hyderabad, etc.
- **Monthly Performance**: Track sales and quantity over each month from January to December.
- **Sales by Mobile Model**: Visual comparison of top-performing devices (e.g., iPhone SE, Galaxy Note 20, OnePlus Nord).
- **Brand Analysis**:
  - Apple: ₹161.6M, 783 transactions
  - Samsung: ₹160.0M, 775 transactions
  - OnePlus, Vivo, Xiaomi also included
- **Payment Method Breakdown**: UPI, Debit Card, Credit Card, and Cash — all contributing fairly evenly.
- **MTD and Year-over-Year Comparisons**: Evaluate Month-To-Date performance and compare with same period last year.
